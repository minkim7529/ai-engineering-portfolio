Vision AI, 두 개의 시대

컴퓨터 비전은 크게 두 흐름으로 나눌 수 있습니다. 2012년 AlexNet 이후 2020년까지는 CNN(합성곱 신경망)이 사실상 표준이었고, 2020년 Vision Transformer(ViT) 등장 이후로는 Transformer 계열이 대형 모델·멀티모달 모델의 표준으로 자리잡았습니다. 두 흐름은 경쟁 관계라기보다 지금은 서로 아이디어를 주고받으며 공존하고 있습니다(Swin Transformer는 CNN의 계층 구조를 Transformer에 들여왔고, ConvNeXt는 반대로 Transformer의 설계 아이디어를 CNN에 되돌려 넣었습니다). 실제로 제가 만든 피부질환 분류기와 졸음방지 독서대의 CNN은 첫 번째 흐름, 아래에서 다룰 ViT·CLIP은 두 번째 흐름에 속합니다.

CNN — 합성곱 신경망

왜 이미지에는 CNN이 잘 맞았나

  • 지역 연결성(locality) — 이미지의 의미 있는 패턴(에지, 질감)은 대부분 근처 픽셀끼리 만들어지므로, 전체가 아니라 작은 영역(커널)만 보는 합성곱이 자연스럽다
  • 파라미터 공유 — 같은 커널을 이미지 전체에 슬라이딩하며 재사용하므로, 완전연결층보다 파라미터 수가 훨씬 적고 위치가 달라져도 같은 패턴을 인식(평행이동 불변성)
  • 계층적 특징 학습 — 층이 깊어질수록 에지 → 질감 → 부분 형태 → 객체 개념 순으로 점점 추상적인 특징을 학습

ResNet — 더 깊게 쌓을 수 있게 만든 아이디어

층을 무작정 깊게 쌓으면 그래디언트 소실로 오히려 성능이 떨어지는 문제가 있었는데, He et al.(2015)의 ResNet은 입력을 몇 개 층 건너뛰어 그대로 더해주는 skip-connection(residual connection)으로 이 문제를 해결했습니다. 이 아이디어 덕분에 100층이 넘는 네트워크도 안정적으로 학습할 수 있게 됐고, 지금도 CNN 설계의 기본 구성요소로 쓰입니다. 제가 만든 피부질환 분류기의 Convbox 블록도 바로 이 skip-connection 구조를 직접 구현한 것입니다 — 입력을 컨볼루션 결과에 그대로 더해줘서 네트워크가 깊어져도 학습이 안정적으로 되도록 만들었습니다.

Vision Transformer (ViT)

자연어처리에서 성공한 Transformer를 이미지에 그대로 적용하면 어떨까 하는 질문에서 시작된 것이 ViT(Dosovitskiy et al., 2020, "An Image is Worth 16×16 Words")입니다. 이미지를 픽셀 단위가 아니라 작은 패치 단위로 잘라서, 패치 하나를 "단어 하나"처럼 취급해 Transformer에 그대로 넣는 것이 핵심 아이디어입니다.

그 이후 — 최신 흐름

모델핵심 아이디어
Swin Transformer이미지를 작은 윈도우로 나눠 그 안에서만 attention을 계산하고, 층마다 윈도우를 옮겨(shifted window) 계산량은 줄이면서도 CNN처럼 계층적 특징을 얻음
ConvNeXtViT의 학습 레시피·설계 아이디어(큰 커널, GELU, LayerNorm 등)를 다시 CNN에 적용해 "현대화된 CNN"으로 ViT급 성능을 회복
CLIP이미지와 텍스트를 같은 임베딩 공간에 놓고 대조 학습(contrastive learning)해, 클래스 이름만으로 별도 학습 없이 분류(zero-shot)할 수 있게 함 — 비전과 언어를 잇는 다리 역할
Segment Anything (SAM)점·박스 같은 프롬프트만으로 이미지의 어떤 객체든 분할(segmentation)할 수 있는 범용 분할 모델
YOLO 계열이미지를 한 번만 보고(single-shot) 객체 위치와 클래스를 동시에 예측하는 실시간 객체 탐지 계열

코드로 보는 ViT 패치 임베딩

CNN은 피부질환 분류기에서 이미 직접 구현해봤기 때문에, 여기서는 상대적으로 낯선 ViT의 핵심 부분 — 이미지를 패치로 잘라 토큰 시퀀스로 바꾸는 patch embedding — 을 PyTorch로 정리합니다. 실제로는 nn.Conv2d를 커널 크기 = 스트라이드 = 패치 크기로 설정하면, 패치 분할과 linear projection을 컨볼루션 연산 한 번으로 동시에 처리할 수 있습니다.

vit_patch_embedding.py — 이미지를 패치 토큰 시퀀스로 변환 
import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2  # 224/16=14 → 14*14=196개

        # 커널 크기 = 스트라이드 = patch_size로 설정하면
        # "패치로 자르기 + flatten + linear projection"이 conv 한 번으로 끝난다
        self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.num_patches + 1, embed_dim))

    def forward(self, x):
        # x: [B, 3, 224, 224]
        x = self.proj(x)                      # [B, 768, 14, 14]
        x = x.flatten(2).transpose(1, 2)       # [B, 196, 768] — 패치 196개, 각각 768차원 토큰

        cls_tokens = self.cls_token.expand(x.size(0), -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)  # [B, 197, 768] — 맨 앞에 [CLS] 토큰 추가
        x = x + self.pos_embed                 # 순서 정보를 더해줌 (attention은 순서를 모르므로 필수)
        return x                                # 이 시퀀스가 Transformer Encoder로 들어간다

실무 적용 — 전이학습

처음부터 학습(from scratch)하는 경우는 실무에서 드뭅니다. ImageNet 등 대규모 데이터로 이미 학습된 모델(ResNet, ViT, CLIP 등)을 가져와 마지막 분류층만 새로 학습하거나, 전체를 낮은 학습률로 미세조정하는 전이학습(transfer learning)이 표준입니다. timm (PyTorch Image Models) 라이브러리를 쓰면 수백 종의 사전학습 모델을 한 줄로 불러올 수 있습니다.

transfer_learning.py — timm으로 사전학습 모델 불러와 미세조정 
import timm

model = timm.create_model("resnet50", pretrained=True, num_classes=4)
# 또는: timm.create_model("vit_base_patch16_224", pretrained=True, num_classes=4)

# 마지막 분류층만 학습하고 나머지는 고정 (데이터가 적을 때)
for name, param in model.named_parameters():
    if "fc" not in name and "head" not in name:
        param.requires_grad = False
한계 / 트레이드오프 — ViT·CLIP 계열은 대량의 데이터와 연산 자원으로 사전학습됐을 때 강력하지만, 데이터가 적은 상황에서 처음부터 학습하면 CNN보다 성능이 떨어지기 쉽습니다(귀납적 편향이 거의 없어서 데이터로부터 모든 걸 학습해야 하기 때문). 실무에서는 데이터 규모, 지연 시간 요구사항, 사전학습 모델의 라이선스를 함께 고려해서 CNN과 Transformer 중 고르거나 둘을 함께 씁니다.

헷갈리기 쉬운 포인트

"ViT가 CNN보다 항상 좋다"는 오해가 흔한데, 원 논문에서도 ViT는 ImageNet 같은 중간 규모 데이터로 처음부터 학습하면 비슷한 크기의 ResNet보다 오히려 성능이 낮았고, JFT-300M 같은 훨씬 큰 데이터로 사전학습했을 때만 CNN을 앞질렀습니다. 즉 ViT의 강점은 구조 자체보다 "대량 데이터 + 사전학습"과 함께일 때 나옵니다. 또한 patch embedding을 "이미지를 자르는 전처리"로 오해하기 쉬운데, 실제로는 학습되는 선형 변환(위 코드의 nn.Conv2d)이라 모델 학습의 일부입니다.

느낀 점 / 앞으로 볼 것

피부질환 분류기에서 skip-connection을 직접 구현해봤을 때는 "그래디언트 소실을 왜 막아야 하는지"를 코드 레벨에서 체감했는데, ResNet 논문을 다시 읽으니 그 구현이 정확히 논문이 말하는 문제의식과 맞닿아 있다는 걸 확인할 수 있었습니다. 다음 학습 주제로는 CLIP을 활용한 zero-shot 분류, 그리고 Segment Anything을 실제로 돌려보며 프롬프트 기반 분할이 어떻게 동작하는지 코드로 확인해볼 계획입니다.
