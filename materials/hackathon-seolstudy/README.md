# 설스터디 — 해커톤 자료

블레이버스 제4회 MVP 개발 해커톤에 6인 팀("세미콜론")으로 출품한 수능 학습
코칭 플랫폼입니다. 본인 담당: 프론트엔드(Next.js App Router, TailwindCSS, Zustand).
