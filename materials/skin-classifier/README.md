# 피부질환 분류 알고리즘 — 자료

3인 팀(구승율, 김민석, 김영준) 수업 프로젝트 발표자료입니다. 본인 담당:
데이터 정제, 모델 학습 및 실행.

## 파일

- [`피부질환 분류 알고리즘.pdf`](피부질환%20분류%20알고리즘.pdf) — 발표자료.
  ResNet 스타일 skip-connection CNN(Convbox) 구조, 데이터셋 코드, 하이퍼파라미터
  스윕(배치 사이즈/에폭/드롭아웃) 실험 결과, 예측 예제가 담겨 있습니다.

## 소스 코드에 대해

이 프로젝트의 Python 소스 코드 파일은 로컬에 별도로 보관되어 있지 않았습니다.
슬라이드 안에 데이터셋 클래스, 모델 정의(`Convbox`, `CustomSkinClassification`),
학습 루프 코드가 스크린샷으로 포함되어 있어 구현 방식은 확인할 수 있습니다.
