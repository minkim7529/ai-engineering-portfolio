# Materials

포트폴리오([../index.html](../index.html))에서 소개한 프로젝트들의 실제 근거 자료입니다.
각 폴더는 포트폴리오 페이지의 한 섹션에 대응합니다.

| 폴더 | 포트폴리오 섹션 | 내용 |
|---|---|---|
| [`vtuber/`](vtuber) | 로컬 LLM 보이스 컴패니언 | Open-LLM-VTuber에 실제로 적용한 코드 diff |
| [`legal-ai/`](legal-ai) | 법률상담 AI | 학습 노트북, 최종보고서, 논문 초안, 데이터/모델 샘플 |
| [`drowsy-reading-stand/`](drowsy-reading-stand) | 졸음방지 독서대 | 발표자료(PDF) |
| [`skin-classifier/`](skin-classifier) | 피부질환 분류 알고리즘 | 발표자료(PDF) |
| [`goods-shop/`](goods-shop) | Goods Shop 웹 프로젝트 | 발표자료(PPTX) |
| [`hackathon-seolstudy/`](hackathon-seolstudy) | 설스터디(해커톤) | 발표자료(PDF) + 팀 공개 저장소 링크 |

## 안내

- **코드가 남아있는 프로젝트**(VTuber, 법률상담 AI)는 실제 소스 코드를 포함했습니다.
- **졸음방지 독서대 / 피부질환 분류 / Goods Shop**은 소스 코드 파일이 따로 보관되어 있지
  않아, 코드가 포함된 발표자료(PDF/PPTX)만 올렸습니다. 슬라이드 안에 실제 코드
  스크린샷과 실행 결과가 담겨 있습니다.
- **설스터디**는 6인 팀 프로젝트라 전체 코드를 이 저장소에 다시 올리지 않고, 이미
  공개되어 있는 팀 저장소로 링크만 연결했습니다.
- 법률상담 AI의 원본 학습 데이터셋(약 75MB)과 학습된 LoRA 가중치(약 27MB)는 저장소
  용량을 위해 전체 대신 샘플/설정 파일만 포함했습니다. 자세한 내용은
  [`legal-ai/README.md`](legal-ai/README.md)를 참고하세요.
