# 졸음방지 독서대 — 자료

2인 팀(7조: 김민석, 김영준) 수업 프로젝트 발표자료입니다.

## 파일

- [`ai 졸음방지 독서대.pdf`](ai%20졸음방지%20독서대.pdf) — 중간발표 자료. Dlib 얼굴
  랜드마크 검출, 직접 설계한 CNN 모델 구조, 학습 데이터셋 구성, 검증 정확도
  (99.65%)와 한계(마스크 착용 시 인식 불가) 등이 담겨 있습니다.

## 소스 코드에 대해

이 프로젝트의 Python/Arduino 소스 코드 파일은 로컬에 별도로 보관되어 있지
않았습니다. 슬라이드 안에 모델 구조, 데이터셋 코드, 학습 결과 스크린샷이
포함되어 있어 구현 방식은 확인할 수 있습니다.
