ABOUT THE WORK

대표작은 파인튜닝, 로컬 LLM 실험, AI 서비스 구현으로 구성했습니다. 로컬에서 돌아가는 실시간 음성 AI부터 법률 도메인 파인튜닝 모델까지, 실험과 서비스 구현을 이어온 작업들입니다. 모델을 돌리는 것 자체보다, 어디서 왜 실패하는지 찾고 고치는 데 시간을 더 많이 썼습니다.

실무형 문제 해결 프로젝트별 프롬프트, 후처리, 주문 검증 로직과 예외 상황을 코드로 다뤘습니다.
모델 실험 경험 로컬/클라우드 백엔드를 비교 실험해보고, 도메인 특화 파인튜닝도 해봤습니다.
협업과 전달력 팀 프로젝트에서 데이터 정제부터 모델 학습, 배포, 보고서 작성까지 맡아봤습니다.
