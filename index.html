ABOUT THE WORK

여기 모아둔 건 대부분 LLM 관련 프로젝트입니다. 로컬에서 돌아가는 실시간 음성 AI부터 법률 도메인 파인튜닝 모델까지, 직접 실험해보고 서비스로 만들어본 것들입니다. 모델을 돌리는 것 자체보다, 어디서 왜 실패하는지 찾고 고치는 데 시간을 더 많이 썼습니다.

실무형 문제 해결 프롬프트, 백엔드 구조, 후처리 파이프라인, 안정성 장치까지 직접 설계했습니다.
모델 실험 경험 로컬/클라우드 백엔드를 비교 실험해보고, 도메인 특화 파인튜닝도 해봤습니다.
협업과 전달력 팀 프로젝트에서 데이터 정제부터 모델 학습, 배포, 보고서 작성까지 맡아봤습니다.
